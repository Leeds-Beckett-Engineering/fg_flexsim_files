# WC.02: Racks and Storage

## Introduction

_Workshop WC.02_ introduces two new objects, the `Rack` and `NetworkNode`, and starts to complete the fundamental knowledge you will need to build (and analyse) your own models. You will have a chance to work with spline points, conveyors, advanced statistics, and global tables: concepts that are used to shape a model to the underlying system being studied in most scenarios.

_Workshop WC.02_ assumes you have worked through _Workshop WC.00_ and _Workshop WC.01_ and are familiar with properties windows. In the previous _Workshops_, almost every step was illustrated to make sure you had a complete understanding of the steps needed to build the model. In _Workshop WC.02_ some of the simple tasks such as adding a new object to the model and entering basic properties will still be identified in the step-by-step description, but screen shots may not be provided.

**Note**: _Workshop WC.02_ will use the model from _Workshop WC.01_ as a starting point. Make sure you have completed _Workshop WC.00_, and _Workshop WC.01_ before starting _Workshop WC.02_.

**Note**: If you are using the Evaluation version of FlexSim, you will **not** be able to complete this model. This Workshop exceeds the number of allowed objects in the _Evaluation_ version. Either use the version in the labs, or contact the Help Desk for instructions on converting to the fully licenced version.

### Learning Outcomes

- How to use global tables to define routings

- How to set up a travel path network for a transporter

- How to create splines in a travel path network

### New Objects

In this Workshop you will be introduced to the `Rack` and `NetworkNode` objects as well as spline points.

### Approximate Time to Complete this Workshop

This Workshop should take about 45-60 minutes to complete
