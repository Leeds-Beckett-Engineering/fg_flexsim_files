# WC.00: Using FlexSim for Simulation

## The Basics

The rest of the Workshop introduces the basic concepts of diagramming and building a simple model. This will help to make the terms we defined above more concrete, as well as introducing the way in which the basic modelling environment in FlexSim works.

**Note:** that for this Workshop we will assume that we have a good idea of the process we are building a simulation for. In most _real_ problems, though, you may have to do some work to obtain the data you need to build the simulation. Building a diagram of the process on paper is also a great way to start every model that you will build in FlexSim. If you can not build a diagram, flowchart, or at least see a picture in your mind of how the process works, you will have a difficult time building the model in FlexSim.

### Learning Outcomes

- How to build a simple layout

- How to connect ports for routing flow items

- How to detail and enter data into `FlexSim` objects

- How to navigate in the animation views

- How to view simple statistics on each `FlexSim` object

### New Objects

In this lesson you will be introduced to the `Source`, `Queue`, `Processor`, `Conveyor`, and `Sink` objects.

### Approximate Time to Complete this Lesson

This lesson should take about 30--45 minutes to complete.
