# WC.05: Traffic Control

## Introduction

This example takes a very simplistic look at how operators can be used to transport flow items along a path/corridor. However one part of the corridor only allows one operators to travel in one direction. Therefore if a second operator came along to the corridor and another operator was already travel down the corridor towards them then they would have to wait and allow them to pass.

### New Objects

This _Workshop_ introduces the _Traffic Control_ feature and network _nodes_.

### Learning Outcomes

- Understand the use of `Trigger`s to modify the behaviour or appearance of an object in FlexSim

- Understand the use of `Trigger`s to create or respond to events in a FlexSim model

- Understand the use of `Label`s in a model, and how these can be created, updated, and used by `Triggers` within the FlexSim model

### Approximate Time to Complete this _Workshop_

This _Workshop_ should take about 30--40 minutes to complete.
