Simulation and Modelling Files
==============================

The files in this repository support the _FlexSim Fieldguide_ (`FLX`) by providing templates and examples as covered in the _Workshops_. These files are collected by FlexSim version as follows

* `2023`: The full version of all the files for examples, problems, and experiments for FlexSim version `2023` and patches. This is the oldest version currently supported by the module material.
* `2025`: These are the same versions as the older ones, but updated for use with FlexSim version `2025`. This is the current version used in the Leeds Beckett labs during the 2026/27 academic year, and the one you should choose if in doubt.
