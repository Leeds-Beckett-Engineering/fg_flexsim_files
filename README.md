Simulation and Modelling Files
==============================

The files in this repository support the _FlexSim Fieldguide_ (`FLX`) by providing templates and examples as covered in the _Workshops_. These files are collected by FlexSim version as follows

* `2023`: The full version of all the files for examples, problems, and experiments for FlexSim version `23` (20023) and above (including 2023 patch versions). This is the oldest version currently supported by the module material.
* `2026`: These are the same versions as the older ones, but updated for use with FlexSim version `26` (2026). This is the current version used in the Leeds Beckett labs during the 2026/27 academic year, and the one you should choose if in doubt.
